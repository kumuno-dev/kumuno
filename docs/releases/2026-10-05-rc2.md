公開後、5配布物の版・タグ・固定tgzのSHA-512一致をRegistryで確認した。公開直後の新規パッケージには一時的な404があり、取得可能になるまで待って確認した。CLIの非対話試行はEOTPで未公開となり、対話ターミナルの本人確認で公開が成功した。

Registryからの新キャッシュ取得で共通8パッケージの独立導入・実行時import/require・公開型が成功。印刷は3画面幅・A4 PDF・複数ページ、管理UIはReact描画とサーバー側importも確認した。公開CLI166ファイルの独立生成・npm ci・lint・型・単体29件・実DB71件・基本ブラウザー4件・本番ビルド、3画面幅の管理/医療/通知操作、開発用PostgreSQLの自動準備・終了/再起動とデータ保持も成功。管理UIの初回Registry検証は反映前の404で失敗したが、取得可能になった後の単独再検証が成功した。正式版のClaude Code受入確認と今回のWindows実行は未実施。

## 試す

```sh
npx create-kumuno@next my-app
cd my-app
npm run dev:local
```

共通機能は既存のアプリへ個別に導入できる。接続とCSS、認証・認可・保存は利用アプリが用意する。

```sh
npm install @kumuno/print@next @kumuno/csv@next @kumuno/notifications@next @kumuno/admin@next
```
