# 0028 医療機器の運用ダッシュボード

2026-10-01、採用。テストデータ選択の次工程として運用状況の入口を追加する。

同じMedicalDevice・貸出・点検・修理をRepeatableReadのスナップショットで集計する。廃棄済み、修理中、貸出中、点検待ち、運用停止、貸出可能の優先順で重複しない分類を定義し、台帳フィルターと同じ関数を使う。各分類の合計は全台数と一致する。点検待ちには修理完了後の停止中も含む。

点検予定は直近の記録のnextInspectionDateを使用する。新しい記録で予定が未入力なら古い予定を持ち越さない。日本時間の今日から7日後までと期限超過を扱い、廃棄済みを除く。早い順に5台まで表示し、対象台数を別に示す。予定日による貸出禁止は追加しない。

小さな業務例としてPrismaの親機器ごとの最新点検取得を使用する。大規模データの性能検証・期限通知・点検表テンプレートは未実装。[利用仕様](../../templates/default/docs/medical-equipment.md)を参照。
