# 0027 任意の医療機器テストデータ

2026-10-01、採用。運用のイメージを掴むため、画面でテストデータあり/なしを選択する。

MedicalDevice.isSampleを追加し、既存機器はfalse。初めて管理権限のあるユーザーが「あり」を選ぶと、架空の7台と貸出・点検・修理の履歴を単一Serializableトランザクションで追加する。MedicalSampleDatasetの組織一意制約で再追加・初期化を防ぐ。番号競合や監査失敗時は全体を取り消す。現役の共通部署・Userを再利用し、現存データを変更しない。

切り替えは削除でなく、台帳・貸出・点検・修理の一覧と医療ダッシュボードの表示範囲を変更する。既定は「なし」。組織に紐づくブラウザーCookieで保持し、権限や組織境界の根拠には使わない。他の利用者の表示を変えない。閲覧ユーザーも表示を切り替えられるが、データ作成は管理権限を再検査する。

テスト機器の識別は編集不可のisSampleと画面の注意文で維持する。非表示時も直接URLで開けるので識別を表示する。履歴や監査を削除する「リセット」は提供しない。分類の実データはテストとして登録しなかったデータを意味する。施設の使用可否や点検基準は保証しない。[利用手順](../../templates/default/docs/medical-equipment.md)を参照。
