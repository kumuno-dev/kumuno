# 0005: ローカルCLIの先行試用

ユーザーのCLI試用依頼によりMilestone 11の最小部分を先行する。現在のテンプレートをコピーするローカルコマンドを提供し、公開版CLIの完成とは区別する。

Node.js 24標準機能のみを使用し、新規依存は追加しない。配布用template組み立てが未実装のため、この試用版はリポジトリ内のtemplates/defaultを参照する。privateを維持しnpm公開しない。CLIをtgz単体で配布することは未対応。

プロジェクト名を制限し、既存ディレクトリ・symlinkには書き込まない。コピーはトップレベルの許可リストに限定し、環境の秘密情報・依存・生成キャッシュを除外する。テンプレート内symlinkを拒否する。失敗時に出力先を自動削除せず、状態を利用者へ伝える。依存インストールは手動で案内する。

CLIの3テストと既存の単体10件・ブラウザー4件、lint・型チェック・ビルドが成功。CLIが生成したリポジトリ外のアプリでnpm ciと本番ビルドも確認する。認証・業務機能・配布物同梱・Windows動作は未完成または未検証。
