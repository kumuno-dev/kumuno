# 0023: 医療機器台帳を最初の医療業務として追加

日付: 2026-10-01。ユーザーはExcelで医療機器を管理しており、指定サイトを参考にした実装を依頼した。

医療固有の管理番号・型式・保証期限を所有するMedicalDeviceを追加し、一般備品Equipmentと区別する。Organization・Department・User・認証・認可・監査は再利用する。一般備品の状態を医療の貸出可否に流用する案は、貸出や点検と混同するため採用しない。同じ機器を両台帳へ二重登録しない。

第一段階は登録・編集・詳細・検索。組織内一意の管理番号と内部UUIDを分離する。資産番号は任意・重複可とし、施設で必須にする場合は後で調整する。状態は台帳のライフサイクルのみで、貸出・点検の保証を意味しない。履歴を残すため削除操作は設けず廃棄済みで扱う。

既定生成物へ業務例として追加する。CLIの業種選択や分離テンプレートは、貸出等の実装範囲を確認してから設計する。既存の生成アプリ・DBは自動書換えしない。新しいMigrationは追加のみとし、既存6Migrationからのデータ保持を検証する。

実装・権限・検証範囲は[台帳仕様](../../templates/default/docs/medical-equipment.md)、将来の工程は[設計案](../design/medical-equipment-template.md)を参照。

検証: macOSのroot check、配布CLIからの生成・単体26件・実DB32件・本番ビルド・3画面幅のブラウザー操作、ローカルDBの停止/再起動後の台帳と監査保持が成功。今回のテストは架空データと独立した一時DBで実施した。
