# 0037: 管理UIをReactパッケージへ抽出する

日付: 2026-10-05。承認済みの追加順の第8段階。

@kumuno/adminはユーザー・部署の入力欄とReact 19のAction送信フォームを提供する。データ取得・認証・権限・保存・監査は生成アプリに維持し、PrismaやNext.jsに依存しない。既存の見た目と入力名を保持して、ユーザー/部署ページと共通フォームを接続する。

Reactはpeer dependencyとしてアプリのReactと共有する。ビルド不要のESMと型定義を配布し、root exportはサーバーで描画できる入力欄、/formはuse clientを維持した対話フォームとする。Reactサーバー環境からrootをimportしてもクライアントHookを読み込まない。

既存Userの資格情報は表示せず、新規時だけ空の初期パスワード欄を作る。親部署の自部署除外は入力補助。保存時の循環・越境・最新権限と監査transactionは既存serviceが保証する。画面の編集可否を認可の代替にしない。

CSSは生成アプリのクラスを使い、パッケージには同梱しない。既存アプリへの追加は同じクラスのCSSと、認可済みデータ・Actionを利用側で渡す。独自権限設計UI・汎用マスタCRUD・全管理ページ生成は後続。DBモデル・Migrationは変更しない。

独立tgzをCLI候補rc.2へ同梱する。npm公開は別工程。入力欄のHTMLエスケープ・資格情報非表示、独立導入・公開型・Reactサーバー側import、生成物の実DBと3画面幅の管理操作を検証する。

API/OpenAPI/MCP公開はユーザー指定により将来へ据え置く。今回の準備で追加した依存は取り消し、公開入口や接続機能は追加しない。
