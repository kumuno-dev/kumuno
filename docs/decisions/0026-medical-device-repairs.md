# 0026 医療機器の修理管理

2026-10-01、採用。ユーザーの次工程の指示に基づき、台帳・貸出・点検に続く修理履歴を実装する。

MedicalRepairを業務固有モデルとして追加し、Organization・User・MedicalDeviceを再利用する。依頼 → 対応中 → 完了の順序を固定し、完了時の対応内容を必須とする。修理中は貸出・点検・運用再開・廃棄を禁止する。完了だけで従来の運用停止理由まで解除しないため、台帳での運用再開と合格点検を必要とする。

既存のSerializableトランザクションと機器行ロックを使用し、未完了の修理を部分一意制約で機器1件に限定する。状態と時刻の整合性をDB制約でも検査する。操作時に最新の権限・有効状態・組織を再確認し、業務更新と監査を原子的に保存する。自由入力は監査へ含めない。日時はDB時刻の明示的な文字列表現から取得する。

Migrationは追加DDLのみ。履歴編集・削除、業者・費用・添付、点検表テンプレートは今回の範囲に含めない。[生成物の仕様](../../templates/default/docs/medical-equipment.md)を参照。
