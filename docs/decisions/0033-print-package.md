# 0033: ブラウザー印刷の共通パッケージ

日付: 2026-10-03

組合せ型構成の第5段階として、@kumuno/printへA4帳票のHTML生成・印刷用CSS・印刷ボタンの静的スクリプトを分離する。Prisma・Next.js・Reactに依存せず、文字列と明示的に選んだ項目だけを受け取る。raw HTMLを受け取らず、全テキストをエスケープする。

最初の業務利用は医療機器の台帳票。アプリ側のログイン・参照権限・組織IDで取得し、別組織と存在しない機器は同じ404にする。個人情報や備考、全履歴を無条件に出力しない。レスポンスはprivate/no-store、CSPを設定し、外部通信・埋め込みを許可しない。静的スクリプトだけを同じオリジンから配信する。

ブラウザーの印刷画面からA4印刷・PDF保存を行う。サーバーPDF生成、電子署名、施設ごとの帳票承認、専用プリンター対応は今回の範囲に含めない。DBモデル・Migrationは変更しない。

未公開の0.1.0-rc.0実tgzをCLI候補0.1.0-rc.2へ同梱する。独立導入・公開型・エスケープ・3画面幅・A4 PDF・複数ページと、認証付きの組織境界を検証する。npm公開は別工程。
