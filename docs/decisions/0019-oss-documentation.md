# 0019: READMEとOSS文書の入口

- 日付: 2026-10-01
- 状態: 採用

## 背景

仕様書第37・38章は思想と開始コマンドをREADME冒頭に置き、長い設計説明よりQuick Startを先に提示する。従来のREADMEは工程履歴・本体の開発手順・生成アプリの試用が混在し、実装済み機能を未実装とする説明も残っていた。

## 決定

READMEはKUMUNOの思想、npm未公開の表示、ローカル試用、生成する機能、参加方法、公開までの残項目へ整理する。詳細な本体セットアップ・DB・検証・CIは[development.md](../development.md)へ移し、[文書一覧](../README.md)で正本と生成アプリ文書の関係を案内する。

CONTRIBUTING.md、SECURITY.md、CHANGELOG.mdとIssue / PRテンプレートを追加する。貢献時の範囲・検証・AI利用、現在の報告方法・検証範囲、未公開の変更履歴を明示する。存在を確認できない固定の非公開窓口や対応期限は約束しない。ライセンス決定・公開窓口の確定・npm公開は公開準備工程に残す。

生成アプリREADMEも現状へ合わせ、DB不要のトップページ確認と、DB・認証が必要な業務画面を区別する。試用では開発DBだけを作り、test / shadow DBは必要な工程で用意する。生成アプリの文書は製品リポジトリの文書へ依存しない。

変更は文書のみ。DB・依存・アプリ動作・GitHubの公開設定を変更しない。ローカルリンクと生成物内の文書を確認し、既存のcheckとtest:packで回帰検証する。
