# 0024: 医療機器の貸出・返却を履歴として管理する

2026-10-01。医療機器台帳に続く工程としてユーザーが実装継続を依頼した。

MedicalLoanを医療機器Domainに追加し、共通のOrganization・Department・Userを参照する。台帳の所属部署・設置場所は所有・保管の情報として残し、現在の貸出先は未返却の履歴から求める。部署名は貸出当時の表示を保存する。

同じ機器への同時貸出は機器行ロック・Serializableトランザクション・未返却の部分一意制約で防止する。貸出中の運用停止・廃棄、停止/廃棄機器の貸出、二度目の返却を拒否する。履歴への組織境界は複合外部キーで守る。担当者は認証済みUserを使い、自由入力の担当者欄を作らない。

返却後の運用について選択肢を提示した。回答がない場合の方針を伝え、返却後は点検待ちとして再貸出を止める案を採用した。台帳編集で解除する操作は提供しない。点検記録と再貸出への復帰は次工程で施設の運用と合わせて実装する。

貸出/返却と監査は同時保存する。返却時は履歴の更新と台帳の点検待ちも同じトランザクションで扱う。患者への割当や臨床上の点検判定は今回の範囲に含めない。

[実装仕様](../../templates/default/docs/medical-equipment.md)を参照。既存生成アプリは自動更新せず、試用は新しく生成したデモで行う。

検証: 配布物からの単体27件・実DB39件・スモーク4件・本番ビルド・PC/タブレット/スマートフォンでの操作が成功。初回のブラウザー検証で、raw SQLのテーブル参照がadapterのschema設定を引き継がない問題を発見した。行ロックはPrismaの組織を絞ったUPDATEでupdatedAtを更新して取得し、生成アプリと同じ接続条件の回帰テストを追加した。貸出・返却と点検待ち・監査の永続保持も再起動で確認した。
