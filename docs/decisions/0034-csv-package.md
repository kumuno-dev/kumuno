# 0034: CSVパッケージと台帳の書出し

日付: 2026-10-03

組合せ型構成の第6段階として@kumuno/csvを追加する。CSVの引用符・改行・BOM・列数の検証と出力を共通化し、DBや医療項目を依存にしない。最大2MiB・10001行・64列・セル10000コード単位で拒否し、切り詰めない。xlsx・Shift_JIS対応は後続とするため外部依存は追加しない。

最初の利用は医療台帳のCSV出力。既存の参照権限と組織境界を通し、一覧と共通の検索条件・状態・運用状況・テストデータ選択を使う。全ページの最大1000台を同一RepeatableReadの読取transactionで出力する。内部ID・組織ID・備考・ユーザー情報・全履歴を含めない。no-storeと固定のattachment名を使う。

[OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection)の数式開始記号と全角・制御文字を参考に、危険な開始文字は出力全体を拒否する。値に自動で引用符やタブを追加して業務値を変えない。拒否時は論理行・列だけを案内し、値やDB例外を出さない。Excel固有の自動型変換は保証せず、管理番号は文字列として読み込む操作を案内する。

parseCsvは文字列の形式検証のみ。DBへの読込には業務項目の対応、部署の解決、重複検査、確認画面、transactionと監査が必要なため、今回の台帳機能は書出しまで。CSV形式の共通読込をDB登録済みとは扱わない。未公開tgzをCLI候補0.1.0-rc.2へ同梱する。
