# 0035: 医療CSVの確認付き新規一括登録

日付: 2026-10-03

医療台帳にUTF-8 CSVのアップロード、全行の確認、明示的な確認後の新規登録を追加する。128KiB・100台に制限し、必須列3つと既存台帳と同じ項目検証を使う。見出しの重複・未知列、ファイル内/既存の管理番号重複、所属部署の不明・同名の曖昧さは保存前に拒否する。部署コード優先で同じ組織内の既存部署を解決し、自動作成しない。

確認結果は操作者・組織・CSVと解決した属性のダイジェスト・10分の期限へ結びつけたHMACで保護する。保存時にCSVと最新の部署/重複を再検証し、確認された内容と一致する場合のみ保存する。Tokenを権限として扱わず、現在の操作者の有効状態と管理権限を毎回確認する。

全件と1台ごとのCREATE監査を同じSerializable transactionに保存する。監査失敗・競合で先行行も取り消す。再送は既存番号とDB一意制約で拒否し、既存台帳は上書きしない。内部ID・組織ID・貸出/点検/修理履歴は取り込まない。テスト機器の再登録も拒否する。取り込んだ機器は実データの点検待ちとし、合格点検後の再貸出規則をそのまま使う。

DBモデル・Migrationと共通CSVパッケージの公開ファイルは変更しない。xlsx/Shift_JIS、既存台帳の更新/削除、列の自動マッピング、大量取込、部署作成は後続。

確認送信ではCSVをBase64で運び、フォーム送信時の改行変換で内容のダイジェストが変わることを避ける。受信時に長さ・形式とUTF-8を確認し、元のCSVを再検証する。Token自体は確認時のCSVと解決済み属性に結びつける。
