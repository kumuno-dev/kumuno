# 0015: 備品管理の参照実装

日付: 2026-10-01

Milestone 9の全必須機能を通常のNext.js / Prismaとして実装する。既存のServer Actions・共通フォーム・権限判定・監査を再利用し、新規依存は追加しない。入力・repository・更新service・HTTP入口・画面をsrc/equipmentへ整理する。

組織IDを必須にし、部署・担当者は複合外部キーで組織境界を強制する。価格はDecimal(14,2)、購入日はDATE。状態は仕様の4値。全ロールが参照、AdminとManagerが管理できる。Managerの業務更新権限とCoreのユーザー／部署管理権限は別のPermissionとして扱う。

検索とページ切替はサーバーで行い、許可したソートキーとIDで安定した順序にする。更新と監査は同一transaction。備考は自由記述なので監査スナップショットへコピーしない。備品削除後も履歴の対象IDは保持する。入力エラー・権限拒否・競合を画面に表示し、未知の例外は固定メッセージとコードのみログ出力する。
