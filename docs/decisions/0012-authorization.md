# 0012: 業務ロールと共通認可

日付: 2026-09-29

Milestone 6としてUser.roleをPrisma enumで追加し、Admin / Manager / Userを提供する。組織単位の単一ロールでv0.1を始める。Better Authの認証モデルを保ち、管理APIを追加する認証プラグインは導入しない。新規依存はない。

仕様書は3ロールと共通化・将来スコープの拡張を定めるが、操作表は未定義。最小権限としてAdminに共有マスタ管理とロール付与、Managerに参照、Userにダッシュボードのみを割り当てた。業務機能の追加時は操作を明示的に増やす。Adminにも組織境界を適用する。

認証後のDB照会でroleを取得し、共通can / assertPermission / requirePermissionを通す。既存ユーザーはUSERへ移行する。Seed再実行による再昇格を避け、ADMINは新しい開発管理者にだけ指定する。細分化データスコープ・ロール変更画面・本番初期管理者プロビジョニングはこの工程に含めない。
