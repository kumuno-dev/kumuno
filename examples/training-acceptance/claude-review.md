# Claude Codeでの後日確認

これはAcceptance Test E用のレビュー依頼。実行前に公開RCからアプリを生成し、training.patchを適用する。アプリ側のREADMEに従いcheck / test:db / test:authを実行できる環境を準備する。この製品リポジトリをClaude Codeの作業フォルダにせず、生成したアプリを開く。

次の依頼をClaude Codeへ渡す:

> この生成アプリのCLAUDE.mdと参照先docsを読んで、社員研修管理の設計をレビューしてください。まず変更せず、Trainingの所有データ、User / Departmentの再利用、Equipmentへの依存、認証と認可の違い、最新操作者の確認、監査の原子性と備考の除外、組織境界、Migration、将来のAPI入口、実行すべきテストを、コードと文書を根拠に説明してください。人事・総務・教育が同じ共有マスタを使うシナリオも説明してください。不足や矛盾がある場合は具体的な箇所を挙げてください。実行した確認と未確認を分けて報告してください。

確認後、日時・Claude Codeの版・対象CLI版・実行環境・説明の正確性・不足点・テスト結果をdocs/acceptance/v0.1.mdへ記録する。文書の存在やこの依頼を用意したことだけでは合格にしない。説明だけでなく、必要な関連ファイルを実際に参照した結果を確認する。
