# 帳票・印刷

医療機器詳細の「台帳票を印刷 / PDF保存」から帳票を開く。「印刷 / PDF保存」でブラウザーの印刷画面を表示し、用紙をA4にする。PDFは送信先をPDF保存にして保存する。印刷後はブラウザーで詳細画面に戻れる。

台帳票には機器名・管理番号・資産番号・種別・メーカー・型式・製造番号・部署・設置場所・状態・購入日・保証期限・返却後の点検待ち・現在の貸出先と発行時刻を出力する。備考や全履歴、ユーザー情報は出力しない。テスト機器は架空データと表示する。発行時点の情報のため、貸出判断には最新の画面を確認する。

## 共通機能と接続

@kumuno/printのrenderPrintDocumentへ、業務側で選んだ文字列のfieldsとtablesを渡す。すべての文字列をエスケープし、raw HTMLを渡さない。PRINT_SCRIPTを/print-client.jsから同一オリジンで配信する。A4縦・16mm余白、印刷時に操作欄を隠し、表の見出しを繰り返す。

GET /dashboard/medical-equipment/[id]/printはrequirePermission("medical-equipment:read")とmedicalDeviceDetailの組織境界を使う。別組織・不正ID・存在しない機器は404。未ログインはログインへ遷移する。PRINT_HEADERSでprivate/no-store、CookieのVary、CSP、nosniffとno-referrerを設定する。帳票表示は読み取りだけでDBを変更しない。静的スクリプトには業務情報を含めない。

別の帳票を追加する場合も認証・権限・組織境界を利用側で確認し、属性を明示的に選ぶ。モデル全体・秘密情報・資格情報を渡さない。

## 検証と範囲

test:authでPC・タブレット・スマートフォンの台帳票表示、印刷ボタン、印刷用表示、未ログインと別組織の拒否を確認する。製品リポジトリのtest:print-packageでは別アプリへのtgz導入・公開型・A4 PDFの用紙サイズ・複数ページ・文字列エスケープを確認する。

PDF保存はブラウザーの機能を使用する。サーバーでのPDF生成・実プリンター・ブラウザー固有のヘッダー/フッター・施設指定様式は未検証。印刷画面のプレビューを確認して保存する。
